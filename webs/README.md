# CNN Lab 本機介面

```bash
cd "."
.venv-macos/bin/python -B -m tools.web_app
```

開啟 http://127.0.0.1:8765 。不需要既有權重：選參數、按「開始訓練」、確認後，就會從零訓練。開啟網頁本身不會啟動工作。

## 使用前準備

先安裝專案相依套件與適用的 TensorFlow 環境。分類圖片放在 `data_animal_pictures/train/<類別>` 和 `data_animal_pictures/val/<類別>`；兩邊使用同樣六類、互不重複的照片。介面不會下載學校資料或預訓練權重。缺少資料或環境時會顯示錯誤。

## 自由實驗與固定比較

- 自由實驗：模型、觀察節點 1／5／10、實際訓練固定 10 輪、Batch 固定 32、學習率 0.00001／0.0001／0.001、Adam／SGD／AdamW／RMSprop。
- 固定比較：固定 10 輪，在相同優化器、學習率及基準版本下比較不同模型；每個模型有 12 種組合。
- 全部自由組合：10 模型 × 3 學習率 × 4 優化器，共 120 組，逐組從頭訓練 10 輪。每組在第 1、5、10 輪保存截至當時最佳權重及曲線，不重新訓練前面幾輪。
- 完整 10 輪的自由實驗也可直接用於固定比較，不複製權重、不重跑。排程沿用僅限相同基準、全部參數相同且完整完成的紀錄；10 輪還須有最佳權重的驗證結果。
- 圖片 160×160 RGB、相同資料與增強、Seed 42；模型維持學習版架構，與論文差異見主 README。Lab 關閉早停，讓 10 輪比較有相同預算。命令列未指定時維持原本早停行為。
- 每組保存最佳驗證 Accuracy 的權重、設定、逐輪 Accuracy／Loss 和耗時。1、5 輪節點不自動計算分類報告；10 輪結束後，用同一份最佳權重計算驗證 Loss、Precision／Recall／F1 和混淆矩陣。不是分別挑各指標的最高值。GoogLeNet 曲線總 Loss 含輔助損失；比較表有完整評估時顯示 main 分類 Loss。
- Adam／RMSprop 不套用 weight decay；SGD／AdamW 為 0.0005，SGD momentum 為 0.9。這是本專案明確固定的優化器設定，不代表所有超參數都已最佳化。

## 進度與取消

頁面顯示排程完成數、目前 Epoch／批次、進度條與耗時。排程一次只執行一組，失敗原因保留，並繼續下一組；低分結果也保留。按取消會取消同一整批尚未執行的工作，目前工作於批次間停止。已產生的資料不刪除，但未完成的工作不列入完整比較。

程式與資料清單版本會記錄在設定中；排隊期間基準改變時，不會悄悄混用。測試集保留到最後，介面沒有測試集評分入口。

紀錄放在 `logs/macos_ui/<實驗代號>`，最佳權重在 `weights/macos_ui/<實驗代號>`。既有檔案不覆寫。錯誤照片只讀驗證集，最多顯示 12 張。

關閉網頁不影響排程。伺服器仍需運行才能啟動下一組；關閉伺服器時當前背景工作仍可繼續，重新啟動後可接續尚未啟動的排程。若某個訓練程序中斷，不自動從最佳權重續訓，避免遺失優化器狀態卻當作原實驗。

此介面只在本機執行，沒有上傳或公開部署。

## 節點保存

新訓練的節點存於該組權重資料夾的 `milestones/epoch_1`、`epoch_5`、`epoch_10`。每個節點保存當時最佳權重、設定副本與截至當輪的 CSV；`milestones.json` 記錄預算輪數、最佳輪數與時間。切換節點只讀取該輪以前的曲線，1／5 輪不顯示未來第 10 輪的分類報告。切換模型、學習率、優化器會尋找相符的既有紀錄，找不到就顯示空值。

舊的獨立 1／5／10 輪實驗保留；未開始的短實驗標為 superseded。舊 10 輪沒有保存過的節點權重不會事後補造，但 CSV 可供查看前綴曲線。遷移時正在進行的舊工作繼續使用已載入的原 callback，其早期節點也不會宣稱已保存。

## Apple GPU（Metal）

本機另有 `.venv-macos-metal` 訓練環境，使用 TensorFlow 2.15.0 與 tensorflow-metal 1.1.0；CPU 的 `.venv-macos` 保留。重建 GPU 環境可執行：

```bash
python3.11 -m venv .venv-macos-metal
.venv-macos-metal/bin/python -m pip install -r requirements-macos-metal.txt
```

`logs/macos_metal_checks/runtime.json` 控制後續派工。只允許專案內固定的 GPU Python 路徑與已驗證模型；未驗證模型仍使用 CPU。新工作將執行環境寫入當次設定及權重旁的 metadata，介面結果與比較表也會標示環境。CPU 和 GPU 的耗時分開判讀；相同 seed 在不同後端不保證數值完全一致。手動重算驗證使用介面伺服器的 CPU 環境，10 輪自動評估則與該次訓練使用相同環境。

GPU 短測試、套件版本及環境鎖定清單在 `logs/macos_metal_checks`。VGG16 固定批次短測試約 CPU 6.19 秒／批、GPU 0.24 秒／批；不含讀圖和增強，且當時另有正式 CPU 訓練，不能直接當作完整訓練加速倍數。模型與優化器未因 GPU 改寫。
